# 一切皆是帖子（Everything is a Post）

这个知识库不提供硬编码的"产品功能"：项目、管理、监控都不是特性，而是用同一种原语——帖子——表达的任务；任何要在知识库上做的动作，都通过新建一个帖子来执行。

- 项目溶解为多选标签（小项目 = 1 帖、复杂项目 = N 帖，由人打标）。
- 管理是任务而非 agent 类型（策展权限随"管理某 tag"这条任务授予，而非随身份）。
- 监控是任务而非功能（新建帖子，让 agent 观察某 tag 下 1-N 帖并产出健康报告；报告即该帖的 current answer）。

**后果**：核心模型极简、可组合性极大——任何"新功能"都只是"一种新的帖子用法"，无需改动核心；代价是没有开箱即用的看板/仪表盘，上手要靠 entry 帖 + 阅读协议降低门槛。
