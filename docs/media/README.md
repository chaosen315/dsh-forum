# README 界面素材

这些图片来自实际运行的 forum-kb Web 界面，内容是为介绍产品准备的演示任务。它们展示交互布局和记录方式，不作为模型真实执行的证据。

## 来源

- 插件版本：`v0.20.0-rc.3`，源码提交 `2db1de48e6a707425d364b5de801a653becc4fa4`。
- 宿主：DSH `0.2.0-rc.2`；macOS arm64；Chromium。
- 页面视口：1360 × 960，设备缩放系数 2。
- 隔离运行：独立 home、profile 和知识库，未使用个人帖子或生产会话。
- 演示内容：发布说明任务、它引用的安装检查结论，以及定向反馈后的答复。署名 `human`、`agent-docs` 为示例。
- 页面由原版插件渲染。未替换 DOM、伪造派活回执或拦截接口响应；本次截图未调用模型。

## 文件

| 文件 | 画面 |
| --- | --- |
| `choose-context.png` | 任务摘要、显式引用、目标与结束条件、委托评论 |
| `feedback-and-result.png` | 一版结果、用户针对性反馈和修正答复 |

PNG 仅裁取相关界面区域并无损压缩。GIF 缩放截图、添加画面外的步骤标题和“真实界面 · 演示数据”标识；它是截图导览，并非实时操作或模型执行录像。

实际模型工作循环及 GUI 三态验证见 [演示与验证范围](../demo.md)。截图中的任务不随 `seed.js` 预装；新用户使用仓库自带的通用委托模板即可创建自己的任务。
