# 给新同事交接工作：三个虚构方案

本题需求：离线阅读，只包含用户选定的帖子，能回查每个结论的来源。
这是用于推理练习的给定事实，不是实际产品评测。

| 方案 | 给定能力 | 代价或限制 |
| --- | --- | --- |
| A 整库快照 | 可离线，保留全部原始记录 | 默认包含所有帖子，接收者需理解完整库结构 |
| B 选定帖摘要 + 来源索引 | 可离线，每项带 post ID / answer ID，只包含所选帖 | 摘要可能过期；需写制作时间，保留来源供复核 |
| C 托管门户 | 浏览器读取，可集中更新 | 要求网络和服务运维；离线阅读未实现 |

本次只需要一次交接；不要求建设长期平台、持续同步或自动发布。
若采纳 B，可选择 project-guide、project-copy 作为内容来源，但生成摘要仍需执行授权。
